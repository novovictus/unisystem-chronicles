# Audio Hum Notes

## Symptom

As acquired, the cabinet has a bad hum through the speaker.

## Initial diagnostic posture

Do not assume the speaker itself is bad. Treat hum as a power, grounding, filtering, amplifier, connector, or harness issue until isolated.

## Inspection checklist

- [ ] Inspect speaker wiring and speaker terminals.
- [ ] Check for hacked grounds or added splices.
- [ ] Inspect edge connectors for oxidation, heat, looseness, or damaged pins.
- [ ] Inspect audio amplifier board/path, if separate from the main board in this configuration.
- [ ] Inspect PSU output ripple under load.
- [ ] Inspect and document electrolytic capacitors in the PSU/audio path.
- [ ] Verify cabinet earth ground and isolation transformer configuration before power work.
- [ ] Confirm whether hum changes with volume control.
- [ ] Confirm whether hum exists with game board disconnected, if safe and applicable.
- [ ] Confirm whether hum changes with monitor load or cabinet door position.

## Notes

The monitor was initially reported solid, so prioritize audio/power path documentation before disturbing monitor/chassis unnecessarily.

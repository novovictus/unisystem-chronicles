# License Notes

This repository distinguishes between original project documentation, preservation metadata, public archive links, and third-party/copyrighted material.

Recommended policy:

- Project-authored Markdown notes may be licensed normally by the repository owner.
- ROM images, game binaries, and decrypted copyrighted binaries should not be committed.
- Manuals, schematics, cards, and cabinet paperwork should be fully preserved when practical through high-resolution scans.
- Large scan masters should normally stay outside Git and be backed up separately.
- Public preservation copies may be uploaded to Internet Archive when appropriate; this repository should then link to the IA item and record provenance, filenames, checksums, and rights/status notes.
- Any third-party document linked or referenced should include a clear source and rights/status note.
- Do not overclaim ownership of third-party manuals or artwork. Describe preservation purpose and known source plainly.

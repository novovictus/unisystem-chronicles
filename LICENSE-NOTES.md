# License Notes

This repository should distinguish between original project documentation and third-party/copyrighted preservation material.

Recommended policy:

- Project-authored Markdown notes may be licensed normally by the repository owner.
- ROM images, game binaries, and commercial copyrighted artwork/manual scans should not be committed.
- Private archival scans may be tracked by manifest, filename, checksum, and condition notes without redistributing the files.
- Any third-party document that is committed should include a clear rights/source note.
